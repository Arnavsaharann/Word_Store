# Word Store

A web application that allows users to search for words and save their meanings for future reference, all in one place. Built using **React**, **Firebase**, and **Material-UI**, Word Store offers a clean, responsive, and user-friendly interface for managing a personal vocabulary list.

## Features

- **Search for Words**: Quickly find definitions, parts of speech, and example sentences for any word.
- **Save Words**: Save words to your personal list for easy access.
- **Delete Words**: Remove words from your list as needed.
- **Responsive Design**: Designed with Material-UI for a clean and responsive user interface.
- **Firebase Integration**: Firebase authentication and Firestore for real-time data storage.

## Technologies Used

- **React**: For building a fast and interactive UI.
- **Firebase**: Used for user authentication and Firestore database to store and retrieve word data.
- **Material-UI**: Provides a clean, modern look and feel for the application.
